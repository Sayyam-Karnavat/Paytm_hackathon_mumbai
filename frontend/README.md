# Paytm ONE — Frontend (React + Vite + Tailwind CSS)

Redesigned institutional-grade interface for **Paytm ONE & Paytm Resolve**, built in accordance with the design guidelines in `DESIGN.md`.

## Features
- **Design System:** Pure white canvas, Coinbase Blue (`#0052ff`) brand accent, full-bleed dark hero (`#0a0b0d`), 100px pill CTAs, 24px rounded cards, and JetBrains Mono tabular numbers.
- **Agentic Capabilities:**
  - Groq LLM multilingual intent orchestration (Hindi, Marathi, English)
  - SerpApi live telecom tariff & flight/transit verification
  - You.com live regulatory policy citations with clickable official circulars
  - Nexconn real-time chat SDK escalation to human dispute specialists
- **Audio & Voice:**
  - Web Audio API real-time synthesis (button clicks, keypad, signature 3-tone Paytm chime)
  - Web Speech API for voice-to-text recognition and text-to-speech feedback

## Running the Frontend

```bash
cd frontend
npm install
npm run dev
```

The application will be live at `http://localhost:3000`.
